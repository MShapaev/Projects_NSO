# Ховрино. График ПД и РД

Интерактивный график разработки документации, зависимости комплектов, исполнители и исходные данные.

Страница находится в `docs/index.html`. В кнопке «Шаблон оформления» доступны шаблон Word и штамп AutoCAD. Скачивание Excel, подсветка зависимостей, поиск и мобильная версия работают в браузере.

Для публикации: Settings → Pages → Deploy from a branch → main → /docs.

Обновление графика выполняется заменой `docs/index.html`.
